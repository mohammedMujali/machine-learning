🏋️ Gym Members Exercise Analysis
📌 Project Overview

This project analyzes gym members' exercise tracking data.
The goal is to explore patterns in workouts, calories burned, heart rate, BMI, and age using data visualization and basic data analysis techniques in Python.

📂 Dataset

The dataset contains information about:

Age

Gender

BMI

Workout Type

Session Duration

Max BPM (Heart Rate)

Calories Burned

🛠 Tools & Libraries Used

Python

Pandas

Matplotlib

Seaborn

Scikit-learn (for encoding)

📊 Analysis Performed

Checking missing values

Data cleaning

Encoding categorical variables

Distribution plots (Histogram)

Scatter plots

Correlation heatmap

Grouping & aggregation analysis
