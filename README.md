# machine-learning

In this course, I expect to understand the basic concepts of machine learning and how computers can learn from data to make decisions or predictions. I want to learn the difference between supervised and unsupervised learning and know when to use each type.

I also expect to learn how to prepare and clean data before using it, because good data is important for building accurate models. Another thing I hope to learn is how to use different algorithms such as Linear Regression, Decision Trees, and K-Nearest Neighbors, and understand how they work.
